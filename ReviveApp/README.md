# Revive App

A native macOS app that turns videos into Apple Live Photos without re-encoding the video.

Drop in a video, pick the clip range, then add it straight to your Photos library or export the files. The interface is available in Traditional Chinese, Simplified Chinese, English, and Spanish.

## Build

```bash
cd ReviveApp
./build.sh            # builds build/Revive.app
./build.sh --install  # builds and installs to /Applications
```

Requires macOS 14+ and Swift 5.9+.
